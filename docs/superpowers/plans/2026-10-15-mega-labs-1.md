# Mega-Labs Catalog + Ladder Implementation Plan (Plan 1 of 3)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the 12 hand-written lab lines with a data-driven 100-line catalog in 10 gated families, enforce invest-to-unlock ladders for labs and workshop batches, and integrate 9 new combat mechanics into the tick.

**Architecture:** One family table in `balance.ts` generates every line (effect key, per-level bonus, cap, time/cost scaling, gate); effects flow through the existing `recomputeStats`/`applyLineDelta` discipline; ladders read lifetime investment counters; new tick mechanics are small guarded branches beside existing ones. Follow-ups: Plan 2 implants, Plan 3 Herald.

**Tech Stack:** TypeScript 5 strict, Vite 5, Canvas 2D, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-15-mega-labs-implants-design.md` (§§2-3)

### Task 2: Tick integration for the new mechanics

**Files:**
- Modify: `src/game/update.ts` (9 branches), `src/game/state.ts` (if helpers needed), `src/state/training.ts` (delta registry for new keys), `scripts/sim.mjs` (mirror)
- Test: `tests/newmechanics.test.ts`

**Interfaces:**
- Consumes: Task 1 fields + delta appliers
- Produces: live thorns/shield/splash/critMult/slow/boss/cache/ultCharge behavior (consumed by Task 3 UI numbers only)

Branches (all guarded, zero-cost when zero):
- Shield: contact damage hits `s.shield` first, spill to hull. Refill `shield=shieldMax` on launch/restart (lifecycle fresh object + main launch).
- Thorns: attacker dealing contact damage takes `thorns * dmgDealt` back (can kill; credit kills normally).
- Splash: on kill, ships within `splashR` px take 30% of `s.dmg` (single hop, no chain).
- CritMult: crits deal `2 + critMult` x.
- Slow: roamers/seekers inside range move `(1 - slowPct)` (cap slowPct effect at 0.5).
- BossMult: `boss` ships take `*(1+bossMult)` from all hits.
- CacheLuck: surge roll +luck% (additive to base chance — read current surge trigger first, keep behavior identical at 0).
- CacheQuality: cache essence `15 * (1+quality)` rounded.
- UltChargeMult: charge gains `* (1+mult)`.

import { describe, it, expect } from 'vitest';
import { freshState } from '../src/game/state.js';
import { tickSim } from '../src/game/update.js';
describe('new mechanics', () => {
  it('shield absorbs before hull', () => {
    const s = freshState(); s.shieldMax = 100; s.shield = 100; s.hull = 500;
    s.ships.push({ id: 1, kind: 'dart', x: 280, y: 270, hp: 100000, dmg: 10, speed: 0, essence: 0 });
    tickSim(s, 1);
    expect(s.shield).toBeLessThan(100); expect(s.hull).toBe(500);
  });
  it('thorns reflect kill credit normally', () => {
    const s = freshState(); s.thorns = 1; s.dmg = 0; s.rate = 0;
    s.ships.push({ id: 2, kind: 'dart', x: 280, y: 270, hp: 5, dmg: 10, speed: 0, essence: 0 });
    tickSim(s, 1);
    expect(s.kills ?? 0).toBeGreaterThan(0);
  });
  it('splash damages neighbors once', () => {
    const s = freshState(); s.dmg = 100; s.splashR = 60;
    s.ships.push({ id: 3, kind: 'dart', x: 200, y: 200, hp: 1, dmg: 0, speed: 0, essence: 0 });
    s.ships.push({ id: 4, kind: 'dart', x: 210, y: 200, hp: 100000, dmg: 0, speed: 0, essence: 0 });
    const hp = s.ships[1].hp;
    tickSim(s, 1);
    expect(s.ships.length).toBeLessThanOrEqual(1);
    expect(hp).toBeGreaterThan(0);
  });
});
