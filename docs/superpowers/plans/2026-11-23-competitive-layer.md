# Echo Spire Competitive Layer Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a deterministic daily run, recordable/replayable ghost traces, an offline-first leaderboard with HTTP upgrade, and shareable run cards to Echo Spire.

**Architecture:** A numeric `rngState` on `GameState` drives a mulberry32 step, replacing the four gameplay `Math.random` call sites so a date seed produces a reproducible run. Runs record a compact sim-time-sampled trace (`[tMs, wave, hullFrac, dmg, kills]`) that renders as a translucent second ring and uploads through a `LeaderboardClient` interface whose default implementation is localStorage-backed with seeded demo ghosts. UI is wired through the existing generated `index.html` id lists and `main.ts`; no backend is required to ship.

**Tech Stack:** TypeScript strict, Vite, Vitest, Canvas 2D, Web Share API, optional HTTP backend via `VITE_LEADERBOARD_URL`.

**Spec:** `docs/superpowers/specs/2026-11-23-competitive-layer-design.md`

## Global Constraints

- All tuning constants live in `src/sim/balance.ts` (project Global Constraint); no magic numbers in feature code.
- `SAVE_VERSION = 2` and key `echospire.save.v1` are unchanged; new GameState fields are optional and backward-compatible. v1 payloads still refuse to load.
- TypeScript strict; ESM imports use `.js` specifiers.
- `npm test` = `npm run typecheck && vitest run`; baseline is 142 passing tests. `npm run build` and `node scripts/sim.mjs` must stay green.
- `index.html` and `src/style.css` are generated by `scripts/gen_index.py` and `scripts/gen_css.py`; add ids/styles to the generators and regenerate. Never hand-edit generated id lists.
- Only gameplay RNG is seeded (`spawning.ts:10`, `update.ts:49`, `update.ts:52`, `update.ts:68`). Cosmetic fx randomness in `render.ts` (shake, sparks) stays `Math.random`.
- Ghost timestamps are **sim time** (`s.timeS * 1000`), never wall clock, so x1/x2/x4 stay aligned.
- Reduced motion (`prefers-reduced-motion: reduce`) stays respected: the ghost ring draws static, without shake.
- Offline-first: `clientFromEnv()` returns the local client when `VITE_LEADERBOARD_URL` is unset.
- Demo ghost names are fixed: `Vango`, `Nyx-7`, `The Wall`. Run-card headline copy is fixed: `I HELD THE LINE TO WAVE {wave}`.

## Review Focus

- **Old save with no `seed`/`mode`/`rngState`** → must hydrate as a normal run with a fresh seed, never NaN RNG. Test pinned in Task 2 Step 1.
- **Speed changed to x4 mid-run** → ghost trace samples use sim time, so playback stays aligned with the player. Test pinned in Task 4 Step 1.
- **Truncated or malformed trace from network/storage** → `decodeTrace` returns `null`, playback no-ops, no throw. Test pinned in Task 4 Step 1.
- **Fetch rejects / 500 from backend** → local client still lists a board and `submit` resolves `{ok:false}` without throwing. Test pinned in Task 6 Step 1.
- **Web Share API missing or user cancels** → run card downloads instead, no unhandled rejection. Test pinned in Task 8 Step 1.
